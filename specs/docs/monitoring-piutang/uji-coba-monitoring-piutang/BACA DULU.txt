UJI COBA MOCKUP - INVOICING, MONITORING PIUTANG, FOLLOW UP PIUTANG, DASHBOARD PLAN BAYAR
=======================================================================================

CARA MEMBUKA
1. Ekstrak dulu file RAR/ZIP ini ke sebuah folder
   (klik kanan > Extract Here / Extract All).
   Jangan membuka index.html langsung dari dalam jendela RAR/ZIP,
   karena file pendukung di folder "lib" tidak ikut terbaca.
2. Buka file "index.html" dengan Google Chrome atau Microsoft Edge
   (klik kanan > Open with > Chrome / Edge).
3. Tidak perlu internet. Tanpa internet tampilan memakai font bawaan
   laptop; isinya tetap sama.

PENTING
- Ini MOCKUP (contoh tampilan), bukan sistem sebenarnya. Data yang tampil
  adalah data contoh, dan "hari ini" di mockup = 2 November 2026.
- Perubahan yang diisi tidak tersimpan. Tekan F5 (refresh) atau tombol
  "Reset data" di kanan atas untuk kembali ke data awal.
- Garis putus-putus ungu = bagian baru / berubah. Bisa dimatikan lewat
  centang "Tandai perubahan" di kanan atas.
- Tabel memakai AG Grid: klik judul kolom untuk mengurutkan, ikon filter
  di judul kolom untuk menyaring, tarik batas judul untuk melebarkan
  kolom, seret judul untuk memindah kolom. Saat data dimuat ulang tampil
  "skeleton" (kotak abu-abu bergerak) sebentar.
- Tombol Download Excel / Export Excel mengunduh file .xlsx sungguhan
  ke folder Downloads.
- Tombol hijau "Tutorial" (kanan atas, di atas judul halaman) membuka menu:
  "Tutorial halaman ini" dan "Alur proses" (Invoice sampai Close, Monitoring
  Piutang, Dashboard Plan Bayar). Alur proses pindah halaman dan membuka form
  sendiri; klik Lanjut / Kembali. Tutorial tidak menyimpan data.
- Di setiap halaman ada bagian "Aturan & skenario uji" (klik untuk membuka)
  yang menjelaskan aturan halaman itu.

MENU YANG BISA DICOBA (di sidebar kiri)
1. Invoicing
2. Monitoring Piutang
3. Follow Up Piutang
4. Dashboard Plan Bayar

SKENARIO UJI
I. Invoicing
   1. Klik pensil oranye pada SPK 052/STM/MKT-SPK/V/26 (WAPU): form Add
      Invoicing terbuka untuk termin berikutnya (Penagihan 3).
   2. Klik Save tanpa isi: Nomor PO, Nomor Faktur, dan COA Penjualan ditandai.
   3. Isi Nomor PO dan Nomor Faktur, pilih COA Penjualan di tabel jurnal,
      lalu Save. Nomor invoice tampil di kolom No. Invoice.
   4. Klik nomor invoice itu: terbuka di Follow Up Piutang.

A. Monitoring Piutang
   1. Lihat card Total, Lancar (0-60 hari), Potensi Macet (61-90 hari),
      Macet (> 90 hari), dan Belum Diterima Customer.
   2. Filter Tahun / Bulan / Tgl invoice (default Semua) dan Company /
      Customer: card dan daftar dihitung ulang.
   3. Klik card Macet: daftar tersaring ke Macet. Klik lagi untuk lepas.
      Tombol "Download Excel" di card Macet mengunduh invoice Macet saja.
   4. Invoice bermasalah (mis. 239/STM/2023) ditandai merah beserta
      keterangannya.
   5. Klik salah satu invoice: muncul detail, data pengiriman, follow up,
      dan riwayat penerimaan.

B. Follow Up Piutang
   Ada 3 tab utama, masing-masing berisi tab anak:
   - PROSES (tempat bekerja): 1. Kirim Invoice, 2. Konfirmasi Diterima,
     3. Follow Up Customer, 4. Tunggu Bayar & Close.
     Card: Belum dikirim, Belum diterima, Belum di-follow up, Tunggu bayar.
   - MONITORING (hanya melihat): semua invoice yang belum close, lengkap
     seperti Visual Control. Tombol "Buka di Proses" membuka invoice di
     tab kerjanya.
   - HASIL & KENDALA: FU Terlambat, Invoice Bermasalah, Invoice Close.
     Card: FU terlambat, Invoice bermasalah, Closed.
   Klik card = buka daftarnya. Pindah tab utama kembali ke tab anak
   terakhir yang dibuka.
   1. Filter Tahun / Bulan default bulan berjalan (November 2026): hanya
      invoice November yang tampil. Pilih "Semua" untuk melihat semua.
   2. Proses > 1. Kirim Invoice: buka 276/STM/2026 > Update, isi tanggal
      kirim dan via, Simpan. 2. Konfirmasi Diterima: isi tanggal terima
      (no resi wajib bila via JNE), no faktur, dan bukti terima (bisa
      Ctrl+V screenshot), Simpan.
   3. Proses > 3. Follow Up Customer (pilih bulan "Semua"): isi jadwal,
      status, keterangan, dan tanggal dilakukan, Simpan. FU yang sudah
      disimpan langsung terkunci dan FU berikutnya terjadwal otomatis.
   4. Pilih status INVOICE BERMASALAH dan tulis kenapa (batal, revisi,
      dll.): follow up berhenti dan invoice pindah ke Perlu Perhatian & Selesai >
      Invoice Bermasalah.
   5. Close hanya di Proses > 4. Tunggu Bayar & Close (ada plan bayar +
      lunas): coba close 245/STM/2026, isi keterangan close. Menu
      Invoicing dan tab lain tidak punya tombol Close.

C. Dashboard Plan Bayar
   1. Bulan default bulan berjalan (November). Card All = total setahun,
      12 card berisi plan bayar dan realisasi per bulan.
   2. Klik card lain atau pilih Bulan / Tgl plan-bayar untuk menyaring.
   3. Ganti Company / Tahun.
   4. Export Excel saat All dipilih (sheet Ringkasan + Rincian + Realisasi)
      dan saat bulan dipilih (sheet Rincian + Realisasi bulan itu).
